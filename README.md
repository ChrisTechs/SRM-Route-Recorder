# Rough Guide on using the Route Recorder Server
## Quick Notes
- The server is for Minecraft 1.21.11
- No clientside mods are required but it is recommended to use https://github.com/ChrisTechs/mc_debug_renderer - updated to 1.21.11 version of original mod
- It is compiled with Java 25 so running it with Java 25 or newer will probably work
- It is developed and tested on Linux and seems to run fine on Windows I have no idea if it works or not on other platforms
- A compiled jar, dungeon rooms, base routes and secret locations are bundled in a zip under Releases
- The Releases are auto generated by github actions after compiling the server
- The minified one uses proguard to very aggressively attempt to make the jar smaller (it seems to work but still has a slight chance of breaking)
- The full jar is the safe one that should always work.
- By default the server loads pearlroutes.json

## Tutorial

if you only want to re record a single step
/rr deleteStep

if you want to re record the route
/rr deleteRoute

/rr start
/rr pause
/rr resume
/rr nextStep or the item
/rr prevStep or the item
/rr stops

is for recording

/rr save - saves the current routes in memory to routes/pearlroutes-current-recording.json

So by default pearlroutes.json is the routes in memory

when you /rr deleteRoute and record routes it changes the route for that room in memory

if you want to load

routes/pearlroutes-current-recording.json

/loadrec

which loads the routes in that file to memory

it never overwrites pearlroutes.json only pearlroutes-current-recording.json gets overwritten

if you want to reload a room

just using

/load room-name

will load the room again using the current routes in memory

You can also use /load 1
to load the first room in alphabetical order

/routes <args>

allows you to change the routes rendering

For chests, items, other interactions for secrets or levers

Right clicking them will record it but the location it records might not be desirable so
you can use

/recording set tnt, item, bat, interact, exit,...
which will set it to your current player position

if you use /recording save it creates 2 files the 
routes/pearlroutes-current-recording.json

But it also generates:

routes/pearlroutes-legacy.json

ignore the pearlroutes-legacy.json file. 

There is still a few issues and bugs but it is in a working state for route recording I think.
